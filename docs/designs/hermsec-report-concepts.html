What happened

Gitleaks identified key material in source, Semgrep identified dangerous shell execution patterns, and OSV/PMG surfaced dependency advisories from lockfiles.

Recommended order

1Contain credentials. Rotate keys and remove secrets from source and history.
2Close execution paths. Replace string shell calls with argument arrays and allowlisted commands.
3Patch known CVEs. Upgrade vulnerable packages and re-run OSV/PMG checks.

Threat model note

If this app is internet-facing, command execution moves from high to critical. If it is local-only and authenticated, severity depends on who can reach the route.
