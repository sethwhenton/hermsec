Why Some Languages Score Low

Node.js, Python, Java score high because Hermsec has dedicated heuristic rules written specifically for those languages.

Go, PHP, Ruby, C, C#, Rust score low because Hermsec only has 1 generic Semgrep rule for each - it can only catch basic command injection, nothing else.

Think of it like: A doctor trained in human medicine diagnoses humans well. Show them a dog, and they can only check basic things - not do a full checkup.

What I Learned

✓ Multi-scanner integration works - combining tools catches more than any single tool alone
✓ Language-specific rules matter - dedicated heuristics 3-5x better than generic rules
✗ Path traversal is a blind spot - 0% detection across all languages
✗ PHP is underserved - only 8% detection, needs dedicated rules
✓ False positive rate is excellent - 0 FPs on new clean projects
✓ Installing missing scanners (gosec, brakeman, flawfinder) would immediately improve coverage
