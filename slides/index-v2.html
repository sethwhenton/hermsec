HermSec
A Field Report

Security review,
made local.

A desktop assistant that inspects a repository, runs the right scanners, validates evidence with agents, and writes clean reports — without sending your code anywhere.

The Tool

HermSec is a local-first desktop security scanner. It profiles each project, selects matching scanners, runs them, and normalizes evidence into readable reports.

Local-firstScanner-backedAgent triagePDF · HTML · JSON
The Study

We compare four review modes — Deep assisted, Single Agent, MoA, and Scanner + MoA — across 20 projects with 184 labelled findings, using efficient non-US models.

Chapter TwoThe Product

Core functionality

A folder becomes a security report.

The harness inspects the repository, selects the right scanners, runs checks, validates evidence, and writes clean reports.

/ 01Project inspectionDetects languages, manifests, lockfiles, and config files before the scan begins.
/ 02Adaptive scannersUses scanner tools that fit the project instead of running every tool every time.
/ 03Live progressThe chat card shows scan stages, scanner status, findings, failures, and final reports.
/ 04Doctor checksConfirms scanners, model provider access, and internet sources are ready.
/ 05Provider setupLoads supported model providers and lets users enable the models they need.
/ 06Automation & reportsScheduled scans and completed reports link directly to the PDF and report folder.
