HermSec

Security review for local code projects.

A desktop assistant that scans repositories, explains evidence, and creates clean reports for developers.

01 Why we built it

Security tools should be easier to run.

Many developers do not run security checks often because setup is slow, reports are noisy, and each language needs different tools.

One simple workflowPick a project, choose the scan mode, and let HermSec handle the scanning steps.
Clear evidenceFindings keep file paths, lines, rules, severity, confidence, and remediation guidance.
Useful reportsThe final output is readable in chat, dashboard pages, JSON, Markdown, HTML, and PDF.
02 Core functionality and product features

Hermsec Features

The harness inspects the repository, selects the right scanners, runs checks, validates evidence, and writes clean reports.

Project inspectionDetects languages, manifests, lockfiles, and config files before the scan begins.
Adaptive scannersUses scanner tools that fit the project instead of running every tool every time.
Live progressThe chat card shows scan stages, scanner status, findings, failures, and final reports.
Automation reportsScheduled scans and completed reports link directly to the PDF and report folder.
03 Research question

Which review mode gives the best security result?

We compared scanner-backed review, single-agent inspection, multi-agent inspection, and Scanner + MoA aggregation using efficient non-US models.

Deep assistedScanners run first. The model summarizes and explains scanner-backed evidence.
Single AgentOne model inspects focused code candidates with bounded read and search tools.
MoASpecialist agents inspect candidates. A judge and aggregator merge accepted evidence.
Scanner + MoAScanners and agents run independently. A judge validates and merges both sources.
